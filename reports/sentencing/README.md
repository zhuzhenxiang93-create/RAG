# Sentencing evaluation reports

`evaluation_v1.json` is generated by `python -m legalmind.cli evaluate-sentencing`. It reports test
size, valid labels, sentence-type Accuracy/Macro-F1/confusion matrix, imprisonment MAE/Median AE/
bucket accuracy, and fine-imposed Precision/Recall/F1 plus positive-fine amount metrics. Never copy
validation, smoke-run or proxy-relevance values into the final test section.

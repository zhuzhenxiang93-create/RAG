# 中文简历项目经历

## 推荐版本

**DocMind-RAG：企业级智能文档分析与可信问答平台**
`Python / FastAPI / BM25 / RRF / Parent-Child Chunking / SQLite / Docker / GitHub Actions`

- 将原文档工具与法律 RAG 项目重构为领域无关的企业知识分析平台，打通
  PDF、DOCX、XLSX、TXT、Markdown 上传解析、结构化分块、索引、检索与问答链路；
  保留页码、章节、表格及父子块关系，支持证据定位与引用。
- 设计可解释 Query Router，根据精确查询、语义问答、表格和跨版本比较动态组合
  BM25、Lite Dense、加权 RRF 与重排通道，并在响应中返回通道分数、排名、
  路由原因和阶段耗时。
- 构建证据驱动的可信决策机制，通过相关性、多路一致性、排名间隔、引用覆盖率和
  冲突惩罚计算置信度；对版本、数值和否定冲突返回 `clarify`，证据不足时
  `abstain`，避免无依据生成。
- 建立可复现消融评测，保存运行环境、配置、原始预测及 MRR、Recall@K、nDCG、
  引用、拒答和冲突指标；在 7 篇文档、14 个问题的小型回归集上如实记录 BM25
  优于当前哈希 Dense 基线，未将负结果包装为模型提升。
- 将 202 类法律 LoRA 分类能力改造成延迟加载可选插件，移除硬编码路径与强制
  CUDA；补充离线演示工作台、Request ID、结构化日志、非 root Docker 部署、
  GitHub Actions 和并发 HTTP 基线脚本。

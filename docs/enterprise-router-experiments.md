## 失败案例

每个失败案例记录：

1. 问题和 Gold 来源；
2. 路由预测；
3. Gold 文档的实际排名；
4. 是路由、召回、融合还是数据标注问题；
5. 修改方案是否只针对单个案例过拟合。

## 结论

V2 改善了格式有效率与路由字段指标，但硬来源过滤使 Recall@10 绝对下降 0.1983。
因此当前 Adapter 仅作为实验产物，不能作为生产默认路由。Oracle 上界说明问题不在
“来源路由是否有价值”，而在训练信号与测试企业分布不一致。

# Current-law RAG versus historical cases

历史案件只提供统计学习标签；独立法规库负责检索指定日期有效规则。法规记录包含文档/条文
ID、正文、公布/生效/失效日期、状态、官方 URL、获取时间和校验和。仅接收全国人大、最高
人民法院、最高人民检察院及中国政府网等权威来源。

当前法条不能改写历史案件标签。版本说明固定为：“模型基于历史案件，法律检索基于指定日期
有效规则。”无法可靠自动下载时只实现 schema、adapter 接口与审计，不用非权威转载站替代。

运行时必须显式传入 `as_of_date`。法规索引保留官方 URL、公布/生效/失效日期、状态、获取时间、
校验和与人工核验状态。缺少适用日期、尚未生效、已经失效或未经人工核验的法规只能进入拒绝
审计，不得作为有效法条展示。证据防火墙同时检查案例证据、法规证据和引用闭包；任一检查失败
均要求人工复核。

# LegalMind-RAG 深挖问题与回答

## 数据

1. **数据从哪里来？** 服务器主文件是 CAIL2018 历史派生数据，154,592 条，SHA256 已记录；当前机器上的下载来源和许可未完全恢复，状态为 `legacy_local_file_unverified`。
2. **为什么没把 748,203 条 rest_data 全放进去？** 它来源未明、标签分布偏斜、内部重复更多，并和主训练文件有 455 条规范化重叠，直接加入会放大噪声。
3. **processed_v2 有多少数据？** 120,393 train、15,032 validation、15,097 test，202 个罪名标签。
4. **为什么不能沿用旧 split？** NFKC 与空白归一化后，旧 train-validation/train-test/validation-test 分别有 13/21/1 条重叠。
5. **案件族怎么定义？** 当前由规范化事实哈希和重复组形成，完全相同或规范化相同事实必须在同一 split。
6. **如何防止标签泄漏？** 规则定位“构成某罪”“应以某罪追究”等结论片段并遮蔽，同时保存命中数、清理标记和事实哈希。
7. **泄漏规则可靠吗？** 自动检查可复现，但命中比例较高，仍需法律人员抽样审核；项目没有把它声明为人工验证。
8. **标签是谁决定的？** 罪名来自原始派生文件，不由 LLM 生成；法条字段缺失时保持空。
9. **为什么是多标签任务？** CAIL 中一案可能包含多个罪名；把每个罪名拆成单独样本会让相同事实对应互相冲突的单标签。
10. **如何处理长尾？** 不复制样本，按训练 support 形成可解释频次区间，并在 Bad Case 中分桶；主要指标仍是整体 Micro-F1。
11. **为什么只报告 Micro-F1？** 用户要求统一主指标，而且它按所有标签 TP/FP/FN 聚合，适合整体多标签性能；同时承认它受高频标签主导。
12. **为什么 test 不调阈值？** 否则测试集信息进入模型选择。阈值只在 validation 上决定，test 只做最终确认。

## QLoRA 与训练

13. **LoRA 原理是什么？** 冻结原权重 `W`，只学习低秩增量 `BA`；推理时等价于使用 `W + scale*BA`。
14. **QLoRA 和 LoRA 区别？** QLoRA 将冻结基座以 4-bit 量化加载，LoRA 可在 BF16/FP16 基座上训练；24 GB 长文本条件下 QLoRA 显存更稳。
15. **为什么 NF4？** 它针对近似正态分布权重设计，是 bitsandbytes QLoRA 的标准 4-bit 数据类型；本项目还启用 double quant 和 BF16 计算。
16. **LoRA 加在哪里？** `all-linear`，覆盖注意力和 MLP 线性层；分类头作为可保存模块保留。
17. **为什么 rank=16？** 是显存和容量的工程起点，没有完成 rank 消融，所以不声称最优。
18. **有效 batch 怎么算？** 单卡为 micro batch × gradient accumulation；当前 4×8=32。
19. **batch 8 为什么不用？** 相同 2,048 token 压力测试中 batch 8 已分配峰值 21.72 GiB 后 OOM，余量不足。
20. **为什么 batch 4 比 2 合理？** 两者有效 batch 相同，batch 4 减少累积次数；实测能完成且峰值 15.24 GiB，保留较安全余量。
21. **动态 Padding 怎么实现？** Collator 调 tokenizer.pad，只补到当前批最长并对齐 8 的倍数，同时单独统计有效和 Padding token。
22. **长度分桶有什么用？** 让相近长度样本同批，2,000 条审计的 Padding Ratio 从随机动态 0.4671 降到 0.0139。
23. **为什么不做 Batch Packing？** 分类样本需要独立池化和标签对齐；Packing 容易引入样本间注意力和分类位置歧义，动态 Padding+分桶收益已经明显。
24. **如何断点续训？** 每个实验目录独立，脚本检测最新 checkpoint；Manifest 记录配置、数据哈希和环境，`--resume-from-checkpoint` 恢复。
25. **Smoke 的 0.0073 是不是模型很差？** 它只有 1,000 条训练和 100 条验证，且目标是验证链路，不可用于质量判断。
26. **历史 0.8296 能写简历吗？** 可以明确写成“历史 10K 分层独立测试”，不能描述成 v2 Full 或 150K 全量结果。

## 长文本

27. **max_length 为什么是 2048？** 依据 tokenizer 长度统计和 4090D 显存测试；不是按字符拍定。
28. **Head+Tail 怎么做？** 保留开头案情背景和结尾结果/量刑情节，中间按预算截断。
29. **句界事实选择怎么做？** 先按中文标点切句，再根据行为、工具、金额、伤情、结果、主观意图、自首等输入线索排序选择。
30. **会不会用金标选择句子？** 不会；测试样本片段选择只读取事实文本。
31. **哪种长文本策略最好？** Full 消融未运行，当前只能说三种均已实现，不能预设结果。

## 检索与 Reranker

32. **案例库是否含测试集？** 不含，只从 v2 train 构建 120,393 案、128,107 Chunk。
33. **Chunk 为什么是 1024+128？** 在局部相关性和上下文完整性之间折中；按 tokenizer 和句界切分，128 overlap 保留边界语义。
34. **为什么中文 BM25 用字符 bigram？** 不依赖外部分词词典，对人名脱敏、金额和法律固定短语更稳，且实现可解释。
35. **为什么选 Qwen3-Embedding-0.6B？** 支持中文和长文本，和当前 Qwen 技术栈兼容，0.6B 能在单卡做本地离线实验；许可证为 Apache-2.0。
36. **Hybrid 怎么融合？** BM25 与 Dense 各自排名后用 RRF 融合，避免直接比较不同尺度分数。
37. **Hybrid 一定比 Dense 好吗？** 本项目 Pilot 中不是；Dense nDCG@10 0.9863，高于 Hybrid 0.9013。
38. **Reranker 有效果吗？** 对 Hybrid 从 0.9013 提到 0.9467，但仍低于 Dense；仅为共享罪名代理 qrels。
39. **Recall@10 为什么很低？** 代理定义把全部同罪名训练案例都视为相关，分母可能上千；Top-10 不可能覆盖大集合，因此需同时看 MRR/nDCG/HitRate。
40. **为什么代理 qrels 不够？** 同罪名案例可能行为方式和争议点完全不同，异罪名案例也可能是有价值的混淆对；需人工法律相关性分级。
41. **难负样本怎么选？** 词面相似但罪名不同，并记录行为方式、结果、主观意图等负样本原因；不从 test 构造训练负例。
42. **Reranker 为什么还没领域微调？** 先评测预训练模型，当前结果表明 Dense 已强，且没有人工 qrels；先补评测数据再决定训练成本。
43. **法条怎么切？** 一条法条作为一个可引用单元，保留法律名、条号、版本、来源 URL 和状态，不按固定字符截断。
44. **为什么法条会检索错？** 长事实中的“犯罪嫌疑人、投案”等程序词会压过构成要件；现改为候选罪名优先，并只补一条事实情节法条。

## 生成、对齐和工程

45. **输出 Schema 有什么？** 罪名、法条、关键事实、缺失信息、相似案例、分析、置信度和人工复核标记。
46. **如何保证引用存在？** 校验每个 case_id 和 article 是否属于本次检索上下文；非法引用使校验失败。
47. **SFT 为什么只训练 Assistant token？** 系统和用户输入是条件，不应成为语言建模目标；真实 tokenizer 已验证 mask 后仍有监督 token。
48. **Prompt Baseline 为什么 Schema 通过率为 0？** 20 条 Smoke 中模型输出自定义中文键和不一致类型，内容可读但不符合严格契约。
49. **100 条 SFT 为什么没改善？** 数据量过小，Adapter 仍沿用中文键且经常不输出 EOS；该结果只证明训练可运行。
50. **为什么不做 DPO/GRPO？** SFT、法条监督和人工 qrels 均未稳定，没有可靠偏好对；此时做 RL 会优化错误目标。
51. **何时做 DPO？** Full SFT 格式稳定、引用可自动验证、Bad Case 形成可重复偏好错误，且普通数据/检索修复无效时。
52. **端到端如何表达不确定性？** 无标签过阈值时返回 `uncertain_below_threshold` 和 `used_fallback`，只传前三候选并强制人工复核。
53. **CPU 或模型缺失怎么办？** 统一入口返回 `degraded_no_classifier/degraded_no_index/degraded_no_statute_index`，仍输出可解析 JSON。
54. **实验如何复现？** 独立实验目录保存配置、数据 SHA256、环境、Manifest、指标和预测；历史目录不覆盖。
55. **目前最该做什么？** 恢复官方 CAIL 原始字段和许可，其次是 200 条人工检索 qrels与生成测试集，再跑 Full 模型实验。

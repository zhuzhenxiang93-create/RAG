# 中文简历项目经历

**LegalMind-RAG：证据与法条约束的刑事案件智能分析系统｜大模型算法工程**

- 重构 CAIL2018 历史派生数据流水线，完成 Unicode 清洗、目标标签泄漏遮蔽、案件族去重和分组切分，构建 120,393/15,032/15,097 条、202 类的多标签数据，并将跨集合精确、规范化文本及案件族重叠降至 0。
- 基于 Qwen3-4B 与 QLoRA 实现罪名分类训练和可恢复实验管理，引入动态 Padding、长度分桶及 Head+Tail/句界长文本策略；4090D 实测比较 batch 2/4/8 后选择 batch 4 + 累积 8，历史 10K 分层实验独立测试 Micro-F1 达 0.8296。
- 构建仅含训练集的 128,107-Chunk 类案库和 452 条法条库，实现 BM25、Qwen3 Dense、RRF Hybrid 与 Qwen3 Reranker；在同一 5K-Chunk Pilot 上完成检索消融，并根据 Dense 优于 Hybrid/Reranker 的实测结果保留可配置路由，避免无收益的固定堆叠。
- 设计严格 JSON 的结构化生成与引用校验链路，所有案例和法条引用均可回溯到当次检索结果；增加阈值回退、不确定性和人工复核机制，并用生成 Bad Case 明确 Full SFT 与 DPO 的进入门槛。

> 数据许可、代理检索 qrels 与 Smoke/Full 边界已在仓库 README 中明确；0.8296 为历史 10K 分层独立测试结果，不是 v2 Full 指标。
